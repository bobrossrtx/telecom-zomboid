# Telecommunications Revival - Project Zomboid Mod

Bring back the internet and telecommunications in Project Zomboid! This mod adds interactive devices like computers, phones, routers, and modems, allowing you to restore network connectivity and digital communication in the apocalypse.

## Features

### 🖥️ Interactive Computers
- **Desktop and Laptop computers** that can be found throughout the world
- **Power-dependent operation** - computers only work when buildings have electricity
- **Internet browsing** - access simulated websites for news, information, and survivor communication
- **Email system** - send messages through the restored network
- **Terminal access** - for advanced users
- **Network connectivity** - requires working router/modem infrastructure

### 📱 Mobile Phones
- **Cell phones and smartphones** with realistic functionality
- **Battery system** - phones drain battery over time and need charging
- **Make calls** - contact other survivors (simulated responses)
- **Send text messages** - communicate with other survivors
- **Contact management** - store and manage phone numbers
- **Signal-dependent** - requires network infrastructure to function

### 🌐 Network Infrastructure
- **WiFi Routers** - create local network coverage
- **Cable Modems** - connect to the broader network
- **Network Switches** - expand network capabilities
- **Server Racks** - for advanced network setups
- **All devices are power-dependent** and require electricity to function

### 🔧 Crafting & Repair System
- **Repair damaged devices** using electronics scrap and tools
- **Craft network cables** from wire and electronics parts
- **Assemble network switches** for expanding connectivity
- **Upgrade routers** with signal boosters
- **Dismantle devices** for parts when needed

### 🎮 Gameplay Integration
- **Context menu interactions** - right-click on devices to use them
- **Progressive restoration** - rebuild telecommunications infrastructure
- **Spawn in realistic locations** - offices, homes, electronics stores
- **Found on zombies** - especially business professionals
- **Vehicle spawns** - find phones in car glove boxes

## Installation

1. Download the latest release
2. Extract the `telecom-zomboid` folder to your Project Zomboid mods directory:
   - **Windows**: `C:\Users\[YourUsername]\Zomboid\mods\`
   - **Linux**: `~/.local/share/Steam/steamapps/common/ProjectZomboid/mods/`
   - **Mac**: `~/Library/Application Support/Zomboid/mods/`
3. Enable the mod in the game's mod menu
4. Start a new game or load an existing save

## How to Use

### Using Computers
1. **Find a computer** in offices, homes, or electronics stores
2. **Ensure the building has power** - restore electricity first
3. **Right-click on the computer** and select "Use Computer"
4. **Computer will boot** - wait a few seconds
5. **Launch applications** from the desktop:
   - **Browser** - Visit websites for information and survivor communication
   - **Email** - Send messages to other survivors
   - **Terminal** - Advanced command-line access
   - **Settings** - Check computer and network status

### Using Phones
1. **Find or loot a phone** from homes, zombies, or vehicles
2. **Right-click on the phone** and select "Use Phone"
3. **Make calls** - dial phone numbers to contact survivors
4. **Send texts** - communicate via SMS
5. **Manage contacts** - save important numbers
6. **Monitor battery** - charge phones when connected to power

### Setting Up Network Infrastructure
1. **Find or craft a router/modem** at electronics stores
2. **Place it in a powered building**
3. **Devices in range will automatically connect** when powered
4. **Use ethernet cables** to extend range
5. **Add signal boosters** to improve coverage

### Crafting & Repairs
- **Repair Computer**: Screwdriver + 2 Electronics Scrap + Electronics Magazine
- **Repair Phone**: Screwdriver + Electronics Scrap
- **Make Network Cable**: 2 Wire + Electronics Scrap
- **Assemble Network Switch**: Screwdriver + 3 Electronics Scrap + Wire + Electronics Magazine
- **Dismantle devices** for parts when needed

## Technical Details

### Network System
The mod features a sophisticated network state management system:
- **Node-based architecture** - each device is a network node
- **Power grid integration** - devices only work with electricity
- **Connectivity tracking** - devices must connect to routers/modems for internet access
- **Persistent state** - network configuration is saved between sessions

### Device Types
- **COMPUTER** - Requires router connection for internet
- **PHONE** - Requires network infrastructure for calls/texts
- **ROUTER** - Provides network connectivity to nearby devices
- **MODEM** - Connects to broader network
- **SERVER** - Advanced network functionality

## Compatibility

- **Project Zomboid Version**: 41.78+
- **Multiplayer**: Server-side network state management (requires server installation)
- **Mod Compatibility**: Should work with most other mods

## Known Limitations

- Internet content is simulated (static responses)
- Phone calls receive automated/random responses
- Network range is simplified (building-based)
- No actual multiplayer communication between players (yet)
