# Textures Directory

This directory is for custom item textures for the Telecommunications Revival mod.

## Required Textures

The mod currently uses default Project Zomboid textures. To add custom textures:

1. Create PNG files for items (32x32 or 64x64 recommended)
2. Name them according to item names:
   - Computer.png
   - Laptop.png
   - CellPhone.png
   - Smartphone.png
   - WifiRouter.png
   - CableModem.png
   - NetworkSwitch.png
   - ServerRack.png
   - EthernetCable.png
   - etc.

3. Place them in this `media/textures/Item/` directory

## Current Status

The mod uses placeholder icons from the base game:
- ElectronicsScrap icon for most electronic devices
- Phoneicon for phones
- Wire icon for cables

Custom textures can be added by the community to enhance visual appearance.
